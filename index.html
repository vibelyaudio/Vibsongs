04 · Protocol FAQ

Integration & Architecture

Standard execution paradigms for audio engineers deploying Kilnwave latent models inside WebAudio and C++ VST pipelines.

How does zero-phase isolation prevent transient smearing?
Kilnwave evaluates minimum-phase filter topologies using forward-backward spectral folding. By processing the envelope bilaterally in the frequency domain, dispersion coefficients collapse to zero across sharp dynamic attacks.
Can Kilnwave run directly inside WebAudio AudioWorklet threads?
Yes. The compiled WebAssembly weights avoid all heap allocations post-initialization. All calculations happen inside pre-allocated ring buffers mapped directly to memory views without main-thread serialization penalties.
What computational overhead does the WebGL visualizer incur?
The hero uses a single low-instruction fragment shader rendering two triangles. It consumes less than 0.4ms GPU time per frame on modern integrated GPUs and automatically throttles down when scrolled out of viewport.
Are training pipelines compatible with standard stem formats?
Native ingestion accepts uncompressed 32-bit floating point WAV, FLAC, and raw PCM interleaved buffers up to 192kHz sampling rates with automated polyphonic pitch detection.
